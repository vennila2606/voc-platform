# Future Enhancements — Not Part of the Current Implementation

These are potential future extensions to the VoC Platform. **None of these
are implemented.** They are documented here for planning purposes only, per
the project requirements (item 16).

- **Multilingual feedback analysis** — detect review language and analyze
  in the original language, or auto-translate before sending to Gemini.
- **Voice-to-text feedback** — allow customers to record spoken feedback,
  transcribed before analysis.
- **Social media feedback integration** — pull mentions/comments from
  platforms like Twitter/X or Instagram as an additional channel.
- **Google Reviews integration** — pull in public Google Business reviews,
  if API access is available/approved.
- **Predictive customer satisfaction** — forecast future CSAT/Voice Health
  Score trends based on historical patterns.
- **Email alerts for critical complaints** — notify relevant department
  staff automatically when a Critical-priority review is submitted.
- **Mobile application** — a dedicated iOS/Android app instead of the
  QR-code-to-web-form flow currently in place.
- **Advanced customer churn prediction** — flag customers whose feedback
  patterns suggest they're at risk of leaving.
- **Image-based review analysis** — analyze uploaded proof photos (e.g.
  damaged product images) with vision AI, not just store them as attachments.

## Explicitly out of scope for now
Per the project requirements, none of the above should be built until
separately requested. This file exists so they aren't forgotten, not as
a to-do list to start on automatically.
